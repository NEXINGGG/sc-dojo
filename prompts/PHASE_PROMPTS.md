# フェーズ別Codexプロンプト

マスタープロンプトで計画を確認した後、順番に使用する。

## Phase 1：基盤

`AGENTS.md` と仕様書に従い、Phase 1だけを実装してください。
React + TypeScript + Viteの基盤、Router、共通レイアウト、デザイントークン、問題データ読込み、型定義、IndexedDB基盤までを対象とします。
通常演習、模試、成績機能はまだ完成させないでください。
ライト・ダークモードの骨格と、ホーム画面の静的表示まで実装してください。
完了後にlint、unit test、buildを実行して結果を報告してください。

## Phase 2：通常演習

Phase 2だけを実装してください。
演習条件、通常演習の回答前・回答後、演習結果、途中保存・再開を実装します。
正解判定と選択肢シャッフルは純粋関数としてテストしてください。
未回答、誤答、お気に入りによる絞込みは次Phaseでも構いません。

## Phase 3：履歴・復習

Phase 3だけを実装してください。
回答履歴、未回答、誤答、お気に入り、カテゴリ・難易度絞込み、バックアップ・復元、全消去を実装します。
不正バックアップで既存データが変更されないテストを含めてください。

## Phase 4：模擬試験

Phase 4だけを実装してください。
30問重複なし、50分、前後移動、問題一覧、見直し、未回答確認、時間切れ、採点、結果保存を実装します。
試験中に正解・解説を表示しないでください。

## Phase 5：成績

Phase 5だけを実装してください。
全体、系統、カテゴリ、難易度、模試履歴を表示します。
回答数が少ない場合の誤解を防ぐ表示を入れ、0除算を防いでください。

## Phase 6：PWA

Phase 6だけを実装してください。
manifest、アイコン、Service Worker、オフラインキャッシュ、更新通知を実装します。
学習履歴を更新処理で消さないでください。
Playwrightでオフラインの主要動線を確認してください。

## Phase 7：仕上げ

全受入基準を照合し、不足を実装してください。
アクセシビリティ、320px幅、iPhone相当幅、PC幅、ライト・ダーク、エラー表示を確認してください。
全検査を実行し、未達項目をチェックリスト形式で報告してください。
