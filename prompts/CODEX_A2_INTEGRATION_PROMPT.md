# Codex Prompt: 科目A-2を既存PWAへ統合

既存のネットワークスペシャリスト科目A-1 PWAへ、科目A-2を追加してください。

作業前に必ず以下を確認してください。

- AGENTS.md
- docs/requirements.md
- docs/implementation-plan.md
- docs/a2-integration-requirements.md
- data/questions.json（既存A-1）
- data/categories.json（既存A-1）
- data/a2-questions.json
- data/a2-categories.json
- IndexedDBスキーマと全移行処理
- 通常演習、復習、お気に入り、模試、成績、バックアップ、PWAの実装
- package.jsonと全テスト

パッケージマネージャーはpnpmに統一し、Gitコミットとpushは行わないでください。

## 目的

A-1とA-2を同じアプリで切り替えて学習できるようにします。A-1の既存問題・履歴・設定を一切失わないことを最優先してください。

## A-2試験仕様

- 40分
- 25問
- 四肢択一
- 60%以上で合格
- 15問以上正解で合格
- 固定模試1: 25問
- 固定模試2: 25問
- ランダム模試: activeなA-2問題から重複なし25問

## 必須実装

1. 科目モデル
   - `subjectId: "a1" | "a2"`
   - 科目別の問題数、模試問題数、制限時間、合格基準を設定オブジェクトで管理
   - 数値を画面へ直書きしない

2. 科目切替えUI
   - ホーム上部又は専用画面でA-1/A-2を選択
   - A-1: 基礎・共通知識
   - A-2: ネットワーク専門
   - 最後に選択した科目を保存
   - 科目切替えで学習データを削除しない

3. 問題データ
   - A-1とA-2のローダを分離又は科目別レジストリへ統合
   - A-2の240問とカテゴリを読込み
   - 問題ID・コード・正解・解説を変更しない
   - A-1とA-2で同じカテゴリ名でも集計を混同しない

4. IndexedDB移行
   - 全ユーザーデータへsubjectIdを追加
   - 既存データはa1として冪等に補完
   - 回答履歴、お気に入り、通常演習セッション・結果、模試セッション・結果、学習日、集計キャッシュに反映
   - 一意制約・複合キーへsubjectIdを含める
   - 失敗時に既存データを削除しない

5. 通常演習・復習
   - 科目ごとにフィルター、未回答、誤答、お気に入りを処理
   - 進行中通常演習は科目別に1件ずつ保存可能とするか、既存仕様を保ちながら切替え時に明確な再開導線を出す
   - A-1/A-2の履歴を混ぜない

6. 模試
   - A-1: 30問50分、18問合格を維持
   - A-2: 25問40分、15問合格
   - 固定模試のquestion_setを科目別に参照
   - タイマーは締切時刻ベース
   - 模試結果と合否を科目別に保存

7. 成績
   - 科目別ダッシュボード
   - 全体表示を設ける場合もA-1/A-2の内訳を明示
   - カテゴリ、誤答、進捗、模試推移は選択科目だけを集計

8. バックアップ
   - formatVersionを上げる
   - 両科目のsubjectIdを保存・復元
   - 旧バックアップはA-1として移行可能にする
   - 復元失敗時は既存データを維持

9. PWA
   - A-2問題・カテゴリデータと遅延チャンクをプリキャッシュ
   - オフラインでA-2通常演習・模試・成績を利用可能
   - 更新後も既存IndexedDBを維持

10. データ検査
   - `scripts/validate-a2-data.mjs`を配置・統合
   - `pnpm run validate:data`でA-1とA-2の両方を検査
   - 可能なら`validate:a2`スクリプトも追加

## テスト

最低限追加してください。

- A-2を240問読み込む
- A-2固定模試1・2が各25問
- A-2ランダム模試が重複なし25問
- A-2は40分
- 15問正解で合格、14問で不合格
- A-1は30問50分18問合格のまま
- 既存データがa1へ移行される
- A-1/A-2のお気に入り・誤答・成績が混ざらない
- 科目切替え後も各科目の途中状態を再開できる
- バックアップ往復で両科目が復元される
- オフラインでA-2ルートと問題データを利用できる
- 主要UIにアクセシブルな名前がある

## 実行コマンド

- `pnpm run validate:data`
- `pnpm run lint`
- `pnpm run format:check`
- `pnpm run test`
- `pnpm run build`
- `pnpm run check`
- `pnpm run test:e2e`
- `pnpm run check:release`

## 完了条件

- A-1/A-2切替えが動作
- A-2通常演習・復習・お気に入りが動作
- A-2模試が25問40分15問合格で動作
- A-1既存データと機能を壊さない
- 両科目の成績・履歴が分離
- バックアップ・復元・PWAが両科目対応
- 問題データに変更なし
- 全検査成功
- コンソールに未処理エラーなし

完了時は、変更ファイル、DBスキーマ、移行方法、科目設定、テスト結果、手動確認方法、未解決事項を報告してください。
