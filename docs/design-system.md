# UIデザインシステム

## 1. デザイン方針

- **読みやすさ最優先**：問題文と選択肢を主役にする
- **迷わない**：各画面の主操作は原則1つ
- **初学者に優しい**：専門用語を詰め込まず、短い補助文を添える
- **試験中は静か**：模試画面では装飾を減らし集中を妨げない
- **アクセシブル**：色だけで意味を伝えない

## 2. 基本色

| 用途 | Light | Dark | 使用例 |
|---|---|---|---|
| Primary | `#2563EB` | `#60A5FA` | 主要ボタン、選択中タブ |
| Primary strong | `#1D4ED8` | `#93C5FD` | 押下、強調 |
| Background | `#F6F8FC` | `#0F172A` | 画面背景 |
| Surface | `#FFFFFF` | `#172033` | カード、モーダル |
| Surface muted | `#EEF3F9` | `#243047` | 補助領域 |
| Text | `#172033` | `#F8FAFC` | 本文 |
| Text muted | `#5F6F85` | `#B8C4D6` | 補足 |
| Border | `#D5DEEA` | `#3A4963` | 枠線 |
| Correct | `#15803D` | `#4ADE80` | 正解 |
| Incorrect | `#B91C1C` | `#F87171` | 誤答 |
| Review | `#B45309` | `#FBBF24` | 見直し |
| Info | `#0369A1` | `#38BDF8` | 情報 |
| Focus | `#7C3AED` | `#C4B5FD` | キーボードフォーカス |

正解・誤答の背景には薄い色を使い、本文コントラストを確保する。

- 正解背景：Light `#ECFDF3` / Dark `#123522`
- 誤答背景：Light `#FEF2F2` / Dark `#3B171B`
- 見直し背景：Light `#FFF7ED` / Dark `#3A2712`

## 3. 系統色

カテゴリ表示は系統単位で色を統一する。

| 系統 | 色 | 用途 |
|---|---|---|
| テクノロジ系 | 青 `#2563EB` | カテゴリチップ、グラフ |
| マネジメント系 | 紫 `#7C3AED` | カテゴリチップ、グラフ |
| ストラテジ系 | 橙 `#C2410C` | カテゴリチップ、グラフ |

カテゴリごとに15色を乱用せず、系統色＋カテゴリ名で識別する。

## 4. タイポグラフィ

端末の日本語システムフォントを使用する。

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "Hiragino Sans",
  "Yu Gothic UI", "Noto Sans JP", sans-serif;
```

| 要素 | サイズ | 太さ | 行間 |
|---|---:|---:|---:|
| 画面タイトル | 24px | 700 | 1.35 |
| セクション見出し | 20px | 700 | 1.4 |
| 問題文 | 18px | 600 | 1.75 |
| 本文・選択肢 | 16px | 400～600 | 1.65 |
| 補助文 | 14px | 400 | 1.55 |
| 小ラベル | 12px | 600 | 1.4 |

「大」は各本文を約1.125倍、「特大」は約1.25倍にする。

## 5. 余白・形状

- 4px単位のスペーシング
- 画面左右余白：16px、タブレット以上24px
- カード間：12～16px
- カード角丸：16px
- ボタン角丸：12px
- チップ角丸：999px
- 最小タップ領域：44×44px
- 影はカード階層の補助だけに薄く使用

## 6. コンポーネント

### 主要ボタン
- Primary色の塗り
- 高さ48px以上
- 画面下部ではSafe Areaを考慮
- 無効時は薄い灰色＋`disabled`属性

### 選択肢カード
- 通常：Surface、1px Border
- 選択中：Primary 2px枠＋薄青背景＋ラジオ選択表示
- 正解後：正解は緑枠＋「正解」、選択した誤答は赤枠＋「あなたの回答」
- 未選択の誤答候補は過度に薄くせず、読める状態を保つ

### 進捗バー
- 問題数の進行を表示
- 数値「12 / 30」を併記
- 色だけに依存しない

### チップ
- カテゴリ、難易度、優先度、見直し状態に使用
- 1画面で多用しすぎない

### 通知
- 成功、注意、エラーにアイコン・見出し・短文を付ける
- 画面下部トーストは重要情報には使用しない

## 7. アイコン

実装時は統一した線画アイコンセットを使用する。絵文字を主要UIアイコンにしない。
画面仕様内の記号は説明用であり、そのまま実装する必要はない。

## 8. アニメーション

- 150～200ms程度
- 画面遷移はフェードまたは短いスライド
- 正解時の過剰な紙吹雪・振動は使用しない
- `prefers-reduced-motion` を尊重する

## 9. ダークモード

- 単純な白黒反転にしない
- SurfaceとBackgroundを分ける
- 緑・赤・橙は暗背景上で文字コントラストを確認する
- グラフは色に加えラベルを表示する
