# 公開前チェックリスト

このチェックリストは、個人利用版を公開する直前に実施する。公開先へのデプロイやGit操作そのものは含めない。

## 自動検査

- [ ] `pnpm run check:release` が成功する。
- [ ] `pnpm run validate:data` が240問・固定模試各30問を検証して成功する。
- [ ] `pnpm run build` 後に `dist/manifest.webmanifest`、`dist/sw.js`、Workboxファイル、PWAアイコンが存在する。
- [ ] PlaywrightのDesktop Chromium、iPhone相当、小型Android相当のテストが成功する。
- [ ] `git diff --check` に空白エラーがなく、`data/questions.json` と `data/categories.json` に意図しない差分がない。

## 手動検査

- [ ] 通常演習、未回答・誤答・お気に入り復習、結果表示、中断・再開を確認する。
- [ ] 固定模試1・2、ランダム模試、見直し、提出、時間切れ、再開、結果を確認する。
- [ ] 成績、カテゴリ詳細、テーマ、文字サイズ、動きの軽減を確認する。
- [ ] バックアップ作成、復元プレビュー、完全置換復元、全消去後の表示設定保持を確認する。
- [ ] 本番buildをpreviewで開き、オフライン再読み込み、回答保存、模試、成績、更新通知を確認する。
- [ ] WindowsのChromeまたはEdge、iPhone Safari、ホーム画面追加後で `docs/manual-test-checklist.md` を確認する。

## アクセシビリティと安全性

- [ ] キーボードのみで下部ナビゲーション、選択肢、送信、ダイアログの主要操作ができ、フォーカスが見える。
- [ ] ライト・ダーク、標準・特大文字で横スクロールや操作不能がない。
- [ ] エラー画面が内部スタックを表示せず、再読み込みとホームへ戻る導線を示す。
- [ ] バックアップ以外の学習データを外部送信せず、外部スクリプト・APIキーが含まれないことを確認する。

## 公開設定

- [ ] `package.json` のバージョンを確認し、バックアップ内の表示と整合することを確認する。
- [ ] HTTPSで配信する（localhost以外ではService Workerに必須）。
- [ ] ドメイン直下かサブディレクトリかを決め、`VITE_APP_BASE`、Manifestの`start_url`・`scope`を確認する。
- [ ] 新版公開後に更新通知から手動更新し、途中演習・模試・学習履歴が残ることを確認する。

## ロールバック

1. 直前の正常な`dist`成果物を保管する。
2. 問題があれば、同じ公開パスで直前の成果物へ戻す。
3. 利用者にはアプリ内の「更新する」または再読み込みを案内する。
4. IndexedDBはService Workerのキャッシュと別であり、ロールバック時も削除しない。
