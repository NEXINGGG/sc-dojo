# 公開後スモークテスト

Cloudflare Pagesで初回公開または更新を行ったあと、Production URLで確認する。ここでの「noindex」はアクセス制限ではない。URLを知る利用者は引き続きアクセスできる。

## PC（Chrome または Edge）

- [ ] HTTPSの`pages.dev`または独自ドメインURLでホーム画面を表示できる。
- [ ] 通常演習を開始し、回答後に正誤・解説・覚える一行を表示できる。
- [ ] 演習を中断して再読み込みし、同じ位置・回答で再開できる。
- [ ] お気に入りの追加、履歴からの確認、誤答復習を利用できる。
- [ ] 固定模試1・2とランダム模試を開始でき、提出後に結果を確認できる。
- [ ] 成績画面、カテゴリ詳細、苦手分野を表示できる。
- [ ] バックアップJSONを作成できる。
- [ ] DevToolsでManifest、Service Worker、PWAアイコンを確認できる。
- [ ] ブラウザのインストール導線からPWAを追加できる。
- [ ] 一度オンラインで開いた後、オフラインで再読み込み、通常演習、模試、回答保存を確認できる。
- [ ] 更新通知、または設定画面の更新確認を利用できる。
- [ ] Consoleに未処理エラー、秘密情報、技術スタックトレースが出ていない。

## iPhone Safari

- [ ] SafariでProduction URLを開く。
- [ ] 共有メニューから「ホーム画面に追加」できる。
- [ ] ホーム画面のアイコンが正しく表示され、Webアプリとして起動できる。
- [ ] standalone表示で通常演習と模擬試験を利用できる。
- [ ] 再読み込み、アプリ終了後の再開、途中演習・途中模試の再開を確認できる。
- [ ] オンライン初回読込み後、オフライン起動とオフライン回答保存を確認できる。
- [ ] オンラインへ復帰後も操作を継続できる。
- [ ] バックアップJSONを作成できる。
- [ ] 特大文字とダークモードで問題文・選択肢・結果が読める。
- [ ] セーフエリア、画面回転、下部ナビゲーション、ダイアログに操作不能や横スクロールがない。

## 更新確認

- [ ] 旧バージョンを起動し、通常演習または模試を途中まで進める。
- [ ] 新しいコミットを`main`へ公開し、Production deploymentの完了を確認する。
- [ ] 旧バージョンに更新通知が表示されることを確認する。
- [ ] 「後で」を選び、学習を継続できることを確認する。
- [ ] 「更新する」を選び、更新後に画面が正常表示されることを確認する。
- [ ] IndexedDBの回答履歴、お気に入り、途中演習、途中模試、模試結果が残っていることを確認する。

## 配信・ヘッダー

- [ ] `/manifest.webmanifest`が`start_url: /#/`、`scope: /`で配信される。
- [ ] `/sw.js`と`/manifest.webmanifest`に長期キャッシュが設定されていない。
- [ ] ハッシュ付き`/assets/*`に長期キャッシュが設定されている。
- [ ] `X-Content-Type-Options`、`Referrer-Policy`、`X-Frame-Options`、`Permissions-Policy`、`X-Robots-Tag`を確認する。
- [ ] `robots.txt`、HTMLのrobots meta、`X-Robots-Tag`がnoindex方針と整合する。
