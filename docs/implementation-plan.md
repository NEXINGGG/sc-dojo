# 推奨実装順序

## Phase 0：確認
- 仕様・データ・プロトタイプを読む
- 問題検査を実行
- 実装計画とリスクだけ提示

## Phase 1：基盤
- React + TypeScript + Vite
- Router、共通レイアウト、デザイントークン
- 問題データ読込みと型定義
- IndexedDB基盤

## Phase 2：通常演習
- 条件選択
- 出題、回答、解説、結果
- 途中保存・再開

## Phase 3：復習・履歴
- 誤答、未回答、お気に入り
- 統計集計
- バックアップ・復元

## Phase 4：模擬試験
- 30問抽選
- 50分タイマー
- 問題一覧、見直し、終了確認
- 採点・結果

## Phase 5：成績
- 系統、カテゴリ、難易度、模試履歴
- 苦手判定

## Phase 6：PWA
- Manifest、アイコン、Service Worker
- オフライン動作
- 更新処理

## Phase 7：品質
- Unit、Component、E2E
- iPhone相当幅・PC確認
- アクセシビリティ確認
- Production build
