# B-1公式PDF解析後の実装決定

## 結論

2023～2025年度の9大問、83解答単位について、次を確定した。

- 設問が掲載されているPDFページ
- 答案欄の数と種類
- 記述式答案の字数上限
- 順不同・複数回答・順序回答の扱い
- 図・表・下線番号の参照
- 自動判定、概念補助付き自己採点、自己採点の区分
- 短答問題の許容表記
- 採点講評から反映する注意事項

## 問題表示方式

公式問題文と図表の全文はアプリ配信物に複製しない。

初期実装は次の方式とする。

1. PCでは公式PDFと答案欄を左右表示する。
2. スマートフォンでは「公式PDF」「答案」のタブを切り替える。
3. オンライン時はIPA公式PDFを開く。
4. オフライン利用を希望する場合は、利用者自身が公式PDFをダウンロードし、
   アプリのファイル選択から端末へ登録する。
5. 登録されたPDFはIndexedDBへBlobとして保存し、外部へ送信しない。
6. 公式PDFそのものをCloudflare PagesやGitリポジトリへ同梱しない。

## 採点方式

### automatic

用語、数値、IPアドレス、記号、選択、順序など、解答が限定されるもの。

- 全角・半角
- 前後空白
- 大文字・小文字
- 一般的な区切り記号

を正規化して判定する。

### concept_assisted_self_grade

短い説明問題。必須概念の有無を参考表示した後、利用者が自己採点する。

### self_grade

複数の書き方があり、公式の詳細採点基準が公開されていない問題。
解答概念と解答例を確認し、利用者が正解相当・部分点相当・復習必要を選ぶ。

## 制約

- アプリの判定をIPAの正式採点として表示しない。
- 非公開の配点を推測しない。
- 公式PDFを登録していないオフライン環境では、問題本文を表示できない。
- 設問要約だけを見て解答させず、必ず公式PDFを正本として表示する。
