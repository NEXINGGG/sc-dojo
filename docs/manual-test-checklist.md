# 手動テストチェックリスト

自動テストでは確認できない端末・ブラウザ固有の挙動を、公開前に確認する。

## Windows + Chrome または Edge

- [ ] `pnpm run build && pnpm run preview` でホームを表示する。
- [ ] DevToolsのApplicationでManifest、Service Worker、PWAアイコンを確認する。
- [ ] 通常演習、誤答復習、固定模試、ランダム模試、成績、バックアップを一巡する。
- [ ] Networkをオフラインにし、再読み込み、通常演習、模試、回答保存、成績表示を確認する。
- [ ] 更新通知の「後で」と「更新する」を確認する。
- [ ] Tab / Shift+Tab / Enterで主要なリンク、選択肢、ダイアログを操作する。

## iPhone + Safari

- [ ] 標準文字と特大文字で320px相当の幅に横スクロールがない。
- [ ] 下部ナビゲーション、固定アクション、ダイアログがセーフエリアと重ならない。
- [ ] ライト・ダークモードで問題文、選択肢、正誤、見直しが読める。
- [ ] Safariの共有メニューから「ホーム画面に追加」を表示できる。

## ホーム画面追加後

- [ ] standalone起動で上部・下部が欠けず、ナビゲーションが利用できる。
- [ ] 設定画面で「この端末に追加済み」または適切な案内が表示される。
- [ ] 初回オンライン読込み後、オフライン準備完了の通知を確認する。

## データ維持

- [ ] 通常演習と模試を途中で閉じ、再起動後に同じ問題順・回答・位置で再開する。
- [ ] バックアップ作成後に全消去し、テーマ・文字サイズを保持したまま復元できる。
- [ ] 新版更新後にも回答履歴、途中セッション、模試結果が残る。
