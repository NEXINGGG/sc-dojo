## 初回起動とインストール

- [ ] HTTPSで初回起動し、白画面・読み込みの無限待ち・Safariエラーがない。
- [ ] 名称が「SC道場」、科目切替が「科目A-1」「科目A-2」「科目B」。旧名称やpilot表示がない。
- [ ] ログインせずA-1演習→A-2演習→B演習へ進める。
- [ ] A-1／A-2各240問、Bは5回・20大問の案内を確認する。
- [ ] オフライン準備完了までオンラインで待つ。
- [ ] Safariの共有→ホーム画面に追加でSCの名称・アイコンを確認する。
- [ ] 現在のアイコン図案は旧「A1」を継続使用している点を確認する。ホーム画面の名称は「SC道場」で、NW版を誤って開いていないことを確認する。
- [ ] PWAを起動し、下部5項目・ノッチ・ホームインジケータ・縦横向きを確認する。
- [ ] NW版も開き、アイコン、学習履歴、ログイン状態が混ざっていない。

## 科目A-1／A-2

- [ ] 各科目で回答→正誤の文字表示→解説→次問が操作できる。
- [ ] 長い問題文・長い選択肢・四択解説を読み切れる。固定ボタンが本文を隠さない。
- [ ] 図表選択肢を選べる。画像の文字・線・数値が読める。
- [ ] 表・コードを専用領域内で左右にスクロールできる。ページ全体は横に溢れない。
- [ ] お気に入り登録→中断→アプリ終了→再起動→再開で回答・位置・お気に入りが残る。
- [ ] 「現在間違えている」「未回答」「お気に入り」、カテゴリ・難易度で絞り込める。
- [ ] 成績・問題履歴に各科目の回答が反映され、別科目の成績と混ざらない。
- [ ] A-1固定模試1／2は30問・50分、A-2固定模試1／2は25問・40分。
- [ ] 模試の回答・見直し・途中再開・提出・結果が操作できる。
- [ ] 画面ロックして数分後に戻ると、残り時間が実際の経過に応じて減っている。

## 科目B

- [ ] 2023秋～2025秋の5回・各4大問へ移動できる。
- [ ] 本文・図表／答案タブ、設問選択、大問切替をタッチで操作できる。
- [ ] 長文、結合セルの表、HTTPヘッダー、コード、ネットワーク図、画像の拡大を確認する。
- [ ] 代表例：2025春問2（長文）、2024秋問1（大きい表）、2024春問4（コード）、2025秋問1（HTTPヘッダー）、2023秋問1（画像）、2025秋問4（多い答案欄）。
- [ ] 日本語IME・改行・字数制限・複数選択・図示答案を操作できる。
- [ ] キーボード表示中にも答案欄と保存状態が読め、他の欄や本文へ移動できる。
- [ ] 入力途中に別アプリへ移動／画面ロック／PWA終了し、再起動して答案を再開できる。
- [ ] 回答確定→公式例・学習用解説→自己採点→復習対象→成績へ反映される。
- [ ] お気に入り・未着手・苦手の絞込みを再起動後も利用できる。
- [ ] 5模試とも4問提示→2問選択→150分で開始できる。
- [ ] 問1と問2を切り替えてもそれぞれの答案が残る。提出後に答案が勝手に変わらない。
- [ ] PDF未登録でもアプリ内本文・図表・答案入力が利用できる。
- [ ] 公式PDFのリンク先／参照ページ／端末登録を確認する（任意機能）。

- [ ] Safari／PWAを完全終了してから再起動する。ブラウザを閉じずに画面だけ戻る検査と区別する。
- [ ] 未閲覧のA-1問題、A-2問題・図表、B本文・表・ログ・画像を開ける。
- [ ] 全科目で回答・保存・再開・お気に入り・成績が動作する。
- [ ] Bの答案確定・自己採点が動作し、PDF未登録で学習が止まらない。
- [ ] 通信復帰後も履歴が残る。

## 公開先と任意の同期

- [ ] SCはNWと別originで配信する。manifest・SW・静的画像がすべてSCのURLで取得される。
- [ ] index、manifest、sw.jsが長期キャッシュされず、ハッシュ付きassetsは長期キャッシュされる。
- [ ] 同期を有効にする場合、実SupabaseでGoogleログイン→3科目保存→別端末受信→オフライン変更→復帰後再試行を確認する。
- [ ] SupabaseのSC scope、user_idによるRLS、NWデータの非変更、別ユーザーの読書き拒否を管理側でも確認する。
- [ ] 同期が未確認なら公開環境のSupabase公開変数を設定せず、既存の端末内学習で公開する。
