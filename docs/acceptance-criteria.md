# 初期版の完成条件（受入基準）

## 1. 問題データ
- `questions.json`から240問を読み込める。
- IDは1～240の連番で重複がない。
- 全問にA～Dの4選択肢、正解、解説、覚える一行、カテゴリ、難易度がある。
- 起動時又はビルド時にデータ検査を行い、不正データがあれば明確なエラーで停止する。
- 問題本文をReactコンポーネントへ直接記述しない。

## 2. 通常演習
- 全問、ランダム、カテゴリ、難易度、未回答、誤答、お気に入りで絞り込める。
- 1問ずつ問題と4択を表示する。
- 選択肢は一つだけ選択でき、未選択では回答ボタンを押せない。
- 回答後は選択肢を変更できない。
- 回答後に正誤、正解、解説、覚える一行を表示する。
- 次の問題へ進め、途中で画面を閉じても演習位置を復元できる。
- 選択肢シャッフルを有効にしても正解判定が変わらない。

## 3. 学習履歴・復習
- 問題ごとに回答回数、正解回数、誤答回数、最終回答、最終正誤を保存する。
- ブラウザを閉じても履歴が消えない。
- 誤答問題、未回答問題、お気に入り問題だけを再出題できる。
- 履歴を全消去する際は確認画面を表示する。
- 学習データをJSONでバックアップ・復元できる。
- 壊れた又は別形式のバックアップは取り込まず、理由を表示する。

## 4. 模擬試験
- 条件に合う問題から重複なしで30問を出題する。
- 50分のカウントダウンを表示する。
- 前後の問題へ移動でき、見直しフラグを設定できる。
- 試験中は正解と解説を表示しない。
- 終了操作時に未回答数を表示して確認する。
- 50分経過時は自動終了し、一括採点する。
- 結果に得点、正答率、未回答数、カテゴリ別成績、誤答一覧を表示する。
- 模試結果を履歴として保存する。

## 5. 成績表示
- 全体、カテゴリ別、難易度別の回答数と正答率を表示する。
- 未回答数、誤答問題数、お気に入り数を表示する。
- 回答履歴がない場合に0除算や表示崩れが起きない。
- 正答率の計算が保存データと一致する。

## 6. PWA・オフライン
- iPhone Safariと主要PCブラウザの最新安定版で利用できる。
- ホーム画面へ追加できるmanifestとアイコンを備える。
- 一度読み込んだ後はオフラインでも問題演習、履歴閲覧、模試ができる。
- オフライン時に外部APIへ依存しない。
- アプリ更新時に問題データと学習履歴を不用意に消さない。

## 7. 操作性・アクセシビリティ
- モバイル幅320px以上で横スクロールを原則発生させない。
- タップ対象は十分な大きさを確保する。
- 文字サイズを変更しても主要操作が隠れない。
- 色だけで正誤を伝えず、文字又はアイコンも併用する。
- キーボードだけでも主要操作ができ、フォーカス位置が視認できる。
- ライト・ダークモードの両方で本文と選択肢が読める。

## 8. 品質・テスト
- `npm run lint`、`npm run test`、`npm run build`が成功する。
- 問題読込み、正解判定、履歴保存、絞込み、模試採点を自動テストする。
- Playwrightで通常演習と模試の主要動線を少なくとも1本ずつ試験する。
- コンソールに未処理例外を残さない。
- 保存データのバージョンを持ち、将来の移行処理を追加できる構造にする。

## 9. 完成判定
上記を満たし、240問の全件データ検査、production build、主要E2Eテストが全て成功し、iPhone実機又はSafari相当環境で通常演習と模試を完了できた時点を初期版完成とする。
