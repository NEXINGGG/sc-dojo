# 科目A-2 統合要件

## 目的

既存の科目A-1 PWAへ科目A-2を追加し、起動時またはホーム画面から科目を選択できるようにする。

## 試験仕様

| 項目 | A-1 | A-2 |
|---|---:|---:|
| 制限時間 | 50分 | 40分 |
| 本番問題数 | 30問 | 25問 |
| 合格基準 | 18問以上 | 15問以上 |
| データ数 | 240問 | 240問 |

## 必須変更

1. `subject_id`を学習データの全主キー・検索条件へ含める。
2. A-1の既存履歴を壊さず、未設定データは`a1`として移行する。
3. A-2の問題IDは1001～1240、コードはA2-001～A2-240を使用する。
4. 通常演習、復習、お気に入り、模試、成績、バックアップを科目ごとに分離する。
5. アプリ全体成績と科目別成績を混同しない。
6. A-2固定模試は25問、ランダム模試も25問、制限時間40分とする。
7. A-2は15問以上正解で合格とする。
8. バックアップ形式を更新し、A-1/A-2の両データを保存・復元する。
9. PWAキャッシュへA-2問題データを含める。
10. 既存のA-1問題文・正解・履歴を変更しない。

## 推奨画面

- ホーム上部に科目切替え: `A-1 基礎` / `A-2 ネットワーク専門`
- 初回だけ科目選択画面を表示
- 最後に選択した科目を表示設定へ保存
- 科目切替え時に進行中セッションがある場合は、保存して切替え可能
- 模試カードに試験時間・問題数・合格基準を明示

## データベース移行

- Dexieスキーマを1段階上げる。
- 既存回答履歴・お気に入り・演習結果・模試結果・セッションへ`subjectId: "a1"`を補完する。
- 複合キー又は一意キーに`subjectId`を含め、A1-001とA2-001の衝突を防ぐ。
- 移行は冪等で、失敗時に既存データを削除しない。

## 完了条件

- A-1/A-2を切り替えて通常演習できる。
- A-2の未回答・誤答・お気に入り演習が動作する。
- A-2の固定模試1・2、ランダム模試が25問40分で動作する。
- 15問正解で合格、14問以下で不合格になる。
- A-1とA-2の履歴・成績が混ざらない。
- オフラインでA-2を利用できる。
- 更新後も既存A-1データが残る。
- 全自動テストとPWAビルドが成功する。
